# Métodos reutilizáveis

O que as doze frentes deixaram como método, não só como resultado.

1. **Protocolo de descoberta:** consulta executável → resultado observado → descoberta candidata → reprodução independente.
2. **Níveis de evidência no reconhecimento de infraestrutura:** separar o que é documentado, o que é inferência e o que é desconhecido (BD-003).
3. **Medição de cobertura antes de qualquer cruzamento:** teste literal → diagnóstico de chave → normalização → cobertura quantificada com query_ref (BD-006, BD-009).
4. **Resultado nulo registrado como achado:** emendas × internações deu Pearson -0,0085, e isso está registrado (BD-003).
5. **Ciclo descoberta → reconciliação:** o número vistoso de funil (R$ 126,66 bi) virou cânone com recorte explícito (R$ 112,1 bi, recurso público 2023), com a divergência explicada (BD-007, BD-008).
6. **Experiência recuperada é hipótese operacional:** ciclo recuperar → aplicar → detectar erro → corrigir registro → retestar (BD-011).
