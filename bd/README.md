# bd: parceria Base dos Dados

Espaço de trabalho da parceria entre a Descoberta Pública e a Base dos Dados (BD).

O que vive aqui:

- **Radar de oportunidades**: pautas, descobertas, investigações e aplicações que podem virar conteúdo ou projeto com a BD.
- **Pautas**: achados e recortes prontos para virar investigação ou publicação.
- **Material SICOR + CAR**: cruzamentos entre crédito rural (SICOR) e Cadastro Ambiental Rural (CAR), com os derivados de pesquisa.

Já existe no repositório:

- `investigacoes-bd/`: acervo integral das investigações feitas no chatbot da BD.
- `colaboracoes/base-dos-dados/`: proposta pública de colaboração e demonstração de capacidades.
