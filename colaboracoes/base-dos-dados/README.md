# Base dos Dados x Descoberta Pública

Proposta de colaboração entre a Base dos Dados (BD) e o projeto Descoberta Pública, baseada em trabalho já executado sobre o catálogo público da BD.

- [Proposta de colaboração](proposta-de-colaboracao.md): o que propomos, em três frentes (produção científica, aplicações e comunicação).
- [Demonstração de capacidades](demonstracao-de-capacidades.md): o caso SICOR x CAR de ponta a ponta, com links para os artefatos reais.

O Descoberta Pública é uma iniciativa independente. A colaboração proposta não condiciona a publicação científica dos trabalhos em andamento.
